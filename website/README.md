# DOFT Website

This directory is reserved for the future public DOFT website.

No framework, publishing system, or final domain has been selected yet. Once
designed, the website should consume consolidated content from `docs/` and the
project map from `references/`, without making the historical code in `legacy/`
a dependency.

## Planned content

- A concise introduction to the theory.
- Consolidated findings and explicit evidence status across Study 01–06.
- A timeline and status for each study.
- Links to related repositories.
- Bibliography, license, and citation guidance.

The website must not execute or import anything from `legacy/`.
