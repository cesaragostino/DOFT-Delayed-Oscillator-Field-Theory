# Citation Guide

## Central repository

The central repository has an evolving Zenodo release series:

- Concept DOI: [`10.5281/zenodo.16965707`](https://doi.org/10.5281/zenodo.16965707)
- Source repository:
  <https://github.com/cesaragostino/DOFT-Delayed-Oscillator-Field-Theory>

The concept DOI identifies the archived release series. The current
central-index reorganization has not yet been published as a new Zenodo
version. Until it is, identify the exact Git commit or GitHub release used in
addition to the concept DOI.

A human-readable citation is:

> Agostino, C. *DOFT — Delayed Oscillator Field Theory*. Central research
> repository. Zenodo concept DOI: 10.5281/zenodo.16965707.

The repository's machine-readable metadata are in
[`CITATION.cff`](../CITATION.cff).
